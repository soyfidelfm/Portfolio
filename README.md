# Fidel Filio Moreno — Portfolio

Personal site for Fidel Filio Moreno, Lead .NET Software Engineer.

Live: [https://www.fidelfm.com](https://www.fidelfm.com)

## Stack

Angular 20, TypeScript, SCSS, EmailJS.

## Local development

```bash
npm install
ng serve
```

Open `http://localhost:4200/`.

```bash
ng build
```

Production output goes to `dist/`.

## Notes

- Contact form and silent visit pings use EmailJS.
- Project live demo URLs are intentionally left empty until they are reviewed.
